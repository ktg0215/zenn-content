## 毎日同じ返信を書いている

「ご連絡ありがとうございます。内容を確認しました。」
「ご都合のよい日時をいくつかお知らせください。」
「請求書を添付にてお送りします。」

自分は個人で Chrome 拡張を作って売っています。メールは 1 日に 10 通くらい返しています。内容は相手ごとに違い、毎回変わるのは宛名と宛先です。

同じような返信を手で打つと、1 通あたり約 1〜2 分かかります（測ったのではなく、自分の感覚です）。

この記事では、Gmail で定型文を使い回す方法を 3 つ並べます。無料の順に書きます。自分が使っているのは、このうち方法 3 の拡張です。

## 方法 1: Gmail の標準機能「テンプレート」

Gmail には最初から定型文の機能があります。名前が何度か変わっていて（旧「返信定型文」）、今は「テンプレート」です。

最初はメニューに「テンプレート」が出てきません。設定で有効にする必要があります。

### 有効にする

1. Gmail 右上の歯車 →「すべての設定を表示」
2. 「詳細」タブ →「テンプレート」を「有効にする」
3. 「変更を保存」

### 定型文を作る

1. 「作成」で新しいメールを開き、本文に定型文を書く
2. 右下の「︙」（その他のオプション）→「テンプレート」→「下書きをテンプレートとして保存」→「新しいテンプレートとして保存」
3. 名前を付ける

### 使う

返信画面で「︙」→「テンプレート」→ 名前を選ぶと、本文に入ります。

### 向いている人・向いていない人

- 追加のインストールが要らないので、会社の PC で拡張を入れられない人はこれ一択です
- 名前や日付は入りません。入れたあとに手で直します
- テンプレートが増えると、メニューの中から探す手間が増えます


## 方法 2: Google Apps Script（GAS）で下書きを作る

Gmail の裏で動く Apps Script を使うと、「相手の名前と日付を埋めた下書き」を関数 1 つで作れます。スプレッドシートに宛先の一覧があって、まとめて下書きを作りたい人向けです。

### 最小の例

script.google.com で新しいプロジェクトを作り、次を貼ります。

```javascript
function createReplyDraft(to, name, dueDate) {
  const subject = '請求書のご送付';
  const body = [
    `${name}様`,
    '',
    'お世話になっております。',
    '請求書を添付にてお送りいたします。',
    `${dueDate}までにお振込みをお願いいたします。`,
    '',
    'よろしくお願いいたします。',
  ].join('\n');
  GmailApp.createDraft(to, subject, body);
}

function test() {
  createReplyDraft('example@example.com', '山田', '10月31日');
}
```

`test` を実行すると、Gmail の下書きに 1 通できます。初回は Gmail へのアクセス許可を求められます（自分のアカウントの中だけで動きます）。

### スプレッドシートから一括で

宛先・名前・期限を並べたシートを読んで、行ごとに `createReplyDraft` を呼ぶと、行の数だけ下書きが並びます。

```javascript
function createDraftsFromSheet() {
  const rows = SpreadsheetApp.getActiveSheet().getDataRange().getValues();
  rows.slice(1).forEach(([to, name, dueDate]) => createReplyDraft(to, name, dueDate));
}
```

### 向いている人・向いていない人

- 「同じ文を、相手を変えて何十通も」という人に向いています
- 返信画面の中で「いま来たメールに 1 通だけ返す」には向きません。スクリプトを開いて実行しに行く手間が入ります
- 初回の許可で「このアプリは Google で確認されていません」の画面が出ます。自分で書いたスクリプトなので「詳細」→「（安全ではないページ）に移動」で進めます


## 方法 3: Chrome 拡張で返信画面の中から入れる

「いま来たメールに、名前だけ変えて 1 通返す」が 1 日に何度もある人は、返信画面の中で定型文を選べる拡張が向いています。

選ぶときに見るとよい点は 2 つです。

1. **Google アカウントへのアクセス許可（OAuth）や Gmail の API を使っていないか**。返信画面に文字を入れるだけなら、どちらも要りません。ただし Gmail の画面の上で動く拡張は、インストール時に「mail.google.com のデータの読み取りと変更」の権限が表示されます（SnapReply も表示されます）。その権限で何をしているか（外へ送っていないか）を説明に書いてあるかを見ます
2. **変数が使えるか**。`{{name}}` のような穴を作れると、名前や期限をその場で聞いてくれます

本文が入る速さ自体は、標準のテンプレートでも拡張でも大きく変わりません（自分の実感です）。拡張で変わるのは、毎回違う宛名を差し替える手間と、その打ち間違いが変数で減るところです。

## 3 つの比較

| | 標準テンプレート | GAS | 拡張 |
|---|---|---|---|
| 費用 | 無料 | 無料 | 無料〜有料 |
| 名前・日付の差し込み | 手で直す | できる | 変数があればできる |
| 1 通だけ返す | ○ | △（スクリプトを開く手間） | ○ |
| まとめて何十通 | × | ○ | × |

自分は使い分けていません。使っているのは拡張だけです。
